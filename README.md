# Universidade Veiga de Almeida

**Aluno:** Israel Messias Gomes Moreira  
**Curso:** Análise e Desenvolvimento de Sistemas  
**Instituição:** Universidade Veiga de Almeida

Este repositório foi criado para registrar os projetos, exercícios e atividades
desenvolvidos ao longo da minha trajetória acadêmica na Universidade Veiga de
Almeida.

O objetivo é acompanhar, do início ao fim da faculdade, a evolução do meu
aprendizado. Cada projeto representa uma etapa desse processo e reúne, na
prática, conceitos estudados em diferentes disciplinas.

Além de documentar meu desenvolvimento acadêmico, este repositório também
funciona como uma fonte de consulta pessoal. Assim, poderei revisitar projetos,
relembrar conteúdos aprendidos, observar minha evolução e aproveitar esses
conhecimentos em novos desafios.

## Objetivos do repositório

- registrar os projetos realizados durante a faculdade;
- documentar os conhecimentos adquiridos em cada disciplina;
- acompanhar minha evolução acadêmica e técnica;
- manter os exercícios organizados para consultas futuras;
- construir um histórico prático do meu aprendizado.

## Organização

Os conteúdos são organizados por período, disciplina e atividade. O repositório
será atualizado gradualmente, conforme novos assuntos forem estudados e novos
projetos forem desenvolvidos durante o curso.

## Propósito

Mais do que armazenar códigos e trabalhos, este espaço representa a construção
do meu conhecimento. Ele servirá como memória da minha jornada na faculdade e
como referência para continuar aprendendo e evoluindo.
